Detailed Description

Horizontal bar graph for an LCD. The bar is drawn into one row, starting at column startX and spanning numCols characters. Each character shows 5 steps, so the bar has a resolution of numCols * 5 steps.

The bar uses the custom characters 0-4 of the display (0: completely filled, 1-4: 1 to 4 filled pixel columns). Any custom characters you defined in these slots are overwritten. Create the bar after lcd.begin(). If the display has a built-in solid block character, you can select it with setFilledChar().
