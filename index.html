LCD Library

Arduino library for HD44780 compatible character LCDs. It has the same API as LiquidCrystal, so existing sketches port with little or no change, and adds:

  • header only code
  • I2C modules (LCD_I2C)
  • a client/server mode: a second cheap microcontroller drives the display, connected via serial or wireless
  • backlight brightness with PWM
  • LCDBarGraph to display bars
  • a declarative menu system
#include <LCD.h>
LCD lcd(12, 11, 5, 4, 3, 2); // rs, enable, d4, d5, d6, d7
void setup() {
lcd.begin(16, 2);
lcd.print("hello, world!");
}
void loop() {}
